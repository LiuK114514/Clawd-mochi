## 3. 电路接线

### ⚠️ 重要警告

- **VCC 必须接 3.3V — 绝对不能接 5V！** 否则会烧毁屏幕！
- 建议使用 **GPIO 8 和 10** 做 SPI 通信（硬件 SPI，速度快）
- **不要使用 GPIO 6/7** 做 SPI

### 接线表

| 屏幕引脚 | ESP32-C3 GPIO | 建议线色 | 说明 |
|----------|---------------|----------|------|
| VCC | 3V3 | 🔴 红色 | 电源正极（3.3V！） |
| GND | GND | ⚫ 黑色 | 共地 |
| SDA | GPIO 10 (MOSI) | 🟠 橙色 | SPI 数据线 |
| SCL | GPIO 8 (SCK) | 🟢 绿色 | SPI 时钟线 |
| RES | GPIO 2 | 🟣 紫色 | 复位 |
| DC | GPIO 1 | 🔵 蓝色 | 数据/命令选择 |
| CS | GPIO 4 | ⚪ 白色 | 片选 |
| BL | GPIO 3 | 🟡 黄色 | 背光控制 |

### 接线示意图

```
 ESP32-C3                    ST7789 屏幕
 ┌─────────────┐            ┌──────────┐
 │ 3V3  ───────┼────────────┼─ VCC     │
 │ GND  ───────┼────────────┼─ GND     │
 │ GPIO 10 ────┼────────────┼─ SDA     │
 │ GPIO 8  ────┼────────────┼─ SCL     │
 │ GPIO 2  ────┼────────────┼─ RES     │
 │ GPIO 1  ────┼────────────┼─ DC      │
 │ GPIO 4  ────┼────────────┼─ CS      │
 │ GPIO 3  ────┼────────────┼─ BL      │
 └─────────────┘            └──────────┘
```

> 💡 **焊接技巧：** 先把线穿过背板的槽位再焊接，这样组装时更整洁。

## 4. 软件环境搭建

### 4.1 安装 Arduino IDE

- 下载 [Arduino IDE 2.x](https://www.arduino.cc/en/software)
- 安装并打开

### 4.2 添加 ESP32 开发板支持

1. 打开 **文件 → 首选项**（或 `Ctrl+,`）
2. 在 **"附加开发板管理器网址"** 中添加：
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. 点击 **"好"** 保存
4. 进入 **工具 → 开发板 → 开发板管理器**
5. 搜索 `esp32`
6. 安装 **"esp32 by Espressif Systems"**（最新版本）

### 4.3 安装所需库

1. **工具 → 库管理**（或左侧库图标）
2. 搜索并安装以下两个库：
   - **`Adafruit GFX Library`** — 图形显示基础库
   - **`Adafruit ST7735 and ST7789 Library`** — ST7789 屏幕驱动

### 4.4 配置开发板参数

**工具** 菜单中设置以下参数：

| 设置项 | 值 |
|--------|-----|
| Board | **ESP32C3 Dev Module** |
| **USB CDC On Boot** | **Enabled** ⬅️ 这步最重要！ |
| CPU Frequency | 160 MHz |
| Upload Speed | 921600 |

> ⚠️ **USB CDC On Boot 必须设为 Enabled**，否则上传会失败！

## 5. 上传程序

### 5.1 获取程序文件

程序文件：`clawd_mochi.ino`（约 46KB，单文件）

### 5.2 上传步骤

1. 用 Arduino IDE 打开 `clawd_mochi.ino`
2. 将 ESP32-C3 通过 USB-C 线连接到电脑
3. **工具 → 端口** → 选择 ESP32 对应的 COM 端口
4. 点击 **上传** 按钮（→ 箭头图标，或按 `Ctrl+U`）
5. 等待编译并上传
6. 看到底部输出 **"Hard resetting via RTS pin..."** 即表示成功 ✅

> ⏱ 首次上传需要下载编译工具链，可能需要几分钟，请耐心等待。

## 6. 组装

### 步骤

1. **试装** — 打印外壳后，先试试屏幕能否放进去，不要急着粘
2. **穿线** — 将 8 根线从背板的槽位穿过
3. **焊接** — 按接线表焊接 ESP32 和屏幕
4. **固定 ESP32** — 用双面胶把 ESP32 贴在背板内侧
5. **固定屏幕** — 用 2 颗 M2×6mm 螺丝穿过屏幕边框孔位固定
6. **走线** — 将 USB-C 线从背板槽位穿出
7. **合盖** — 盖上背板

### 组装示意图

```
 ┌──────────────────────────────┐
 │      外壳主体 (橙色 PLA)      │
 │  ┌────────────────────────┐  │
 │  │   屏幕窗口              │  │
 │  │   ┌──────────────┐     │  │
 │  │   │  ST7789      │     │  │
 │  │   │  1.54" TFT   │     │  │
 │  │   └──────────────┘     │  │
 │  │   M2螺丝固定            │  │
 │  └────────────────────────┘  │
 │                              │
 │   ┌────────────────────┐    │
 │   │  ESP32-C3 (双面胶) │     │
 │   └────────────────────┘    │
 │                              │
 │   USB-C 线从此穿出 ──→       │
 ├──────────────────────────────┤
 │       背板 (黑色)            │
```

## 7. 使用指南

### 开机与连接

1. 通过 USB-C 给 ESP32 供电（充电器、充电宝、电脑均可）
2. 等待约 3 秒，屏幕播放开机动画
3. 在手机或电脑上打开 **WiFi 设置**
4. 连接热点：
   - **网络名称：** `ClaWD-Mochi`
   - **密码：** `clawd1234`
5. 打开浏览器访问：**`http://192.168.4.1`**

> 📱 手机和电脑都可以控制，不需要安装任何 App。

### 控制面板功能

| 按钮/控制 | 功能 |
|-----------|------|
| **Normal eyes** | 正常像素眼睛模式（带眨眼+摆动动画） |
| **Squish eyes** | `> <` 眯眼开心表情（带开合动画） |
| **Claude Code** | 显示代码画面 + 伪终端效果 |
| **Canvas** | 进入绘画模式，在手机上画画实时显示在屏幕 |
| **Speed slider** | 控制动画速度（慢/正常/快） |
| **Background color** | 切换所有画面的背景颜色 |
| **Pen color** | 设置画布绘画颜色 |
| **Display on/off** | 切换屏幕背光 |
| **✓ done**（画布中） | 退出画布模式 |

## 9. 排错指南

### ❌ 上传失败

| 原因 | 解决方法 |
|------|----------|
| USB CDC On Boot 未启用 | 在工具菜单中设为 **Enabled** |
| 端口未选对 | 检查 **工具 → 端口** 是否选择了正确的 COM 口 |
| 驱动未安装 | 安装 CH340/CP210x 驱动（取决于 ESP32-C3 的 USB 芯片） |
| 线缆问题 | 确保 USB-C 线支持 **数据传输**（非仅充电线） |

### ❌ 屏幕不亮或不显示

| 原因 | 解决方法 |
|------|----------|
| VCC 接错 | 检查是否接到 **3V3**（不是 5V） |
| BL 未接 | 检查 BL 引脚是否接到 GPIO 3 |
| 接线松动 | 重新插拔或焊接杜邦线 |
| 屏幕损坏 | 检查屏幕是否在运输中损坏 |

### ❌ 连不上 WiFi

| 原因 | 解决方法 |
|------|----------|
| 热点名大小写 | 确认是 **`ClaWD-Mochi`**（大小写敏感） |
| 密码错误 | 密码是 **`clawd1234`** |
| ESP32 未启动 | 等待 3 秒开机动画结束后再尝试 |
| 供电不足 | 换一个充电器或直接插电脑 USB 口 |

### ❌ 屏幕画面异常

| 原因 | 解决方法 |
|------|----------|
| SPI 引脚接错 | 检查 SDA→GPIO 10, SCL→GPIO 8 |
| 接线接触不良 | 重新插拔 SP 接线 |
| 程序未正确上传 | 重新编译上传一次 |
